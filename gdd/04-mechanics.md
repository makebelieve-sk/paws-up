# Игровые механики

---

## 1. Передвижение и управление

### Базовое передвижение
- **WASD** — ходьба
- **Shift** — бег (быстрее, но шумнее — привлекает Кошмара в стелс-зонах)
- **Пробел** — прыжок (невысокий, кошачий — запрыгнуть на ящик, бочку, забор)
- **Ctrl** — красться (медленнее, но бесшумно — ключ к стелс-секциям)
- **Мышь** — управление камерой

### Кошачья акробатика
- Запрыгивание на объекты (ящики, крыши, заборы) — автоматически при прыжке у края
- Карабкание по определённым поверхностям (водосточные трубы, деревья)
- Мягкое приземление — Пьер не получает урон от падений (он же кот)
- Протискивание в узкие щели (недоступные для Кошмара)

## 2. Камера 3-го лица

### Основной режим
- Cinemachine FreeLook — свободное вращение вокруг Пьера
- Три уровня высоты (низко/средне/высоко) для разных ситуаций
- Автоматическое избегание стен (Cinemachine Collider)
- Плавное приближение в тесных помещениях (канализация, чердак)

### Специальные режимы камеры
- **Диалог:** Камера переключается на ракурс «через плечо», показывая собеседника
- **Стелс:** Камера чуть дальше и выше, чтобы видеть окружение
- **Кошачий нюх:** Лёгкий zoom-in, эффект пост-обработки
- **Катсцены:** Timeline-управляемая камера
- **Осмотр улики:** Крупный план предмета, можно вращать

## 3. Система взаимодействия

### Механика
- При приближении к интерактивному объекту появляется подсказка: «[E] Осмотреть» / «[E] Поговорить» / «[E] Подобрать»
- Определение объекта: Raycast от камеры, радиус ~2-3 метра
- Единый интерфейс `IInteractable` для всех объектов

### Типы взаимодействия
| Тип | Действие | Примеры |
|-----|---------|---------|
| Осмотреть | Пьер комментирует объект | Витрина, дверь, след |
| Подобрать | Предмет добавляется в инвентарь | Улики, сыр, колбаса |
| Поговорить | Запуск диалога Yarn Spinner | Все NPC |
| Использовать | Применить предмет из инвентаря | Колбаса для отвлечения |
| Открыть | Дверь / люк / ящик | Двери, люк канализации |

## 4. Кошачий нюх

### Активация
- Кнопка: **Q** (или зажать ПКМ)
- Полоска энергии нюха — тратится при использовании, восстанавливается со временем
- Длительность: ~10 секунд при полной шкале
- Восстановление: ~20 секунд до полной

### Визуальные эффекты
- Мир десатурируется (цвета приглушаются)
- Интерактивные объекты подсвечиваются цветным контуром:
  - Жёлтый — улики и ключевые предметы
  - Синий — информационные объекты
  - Красный — опасность (Кошмар, ловушки)
- Запахи визуализируются как цветные частицы-потоки:
  - Колбаса — красноватый след
  - Сыр — жёлтый след
  - Псина — коричневый след
- Скрытые следы на полу становятся видны
- Потоки воздуха визуализируются (подземные ходы, щели)

### Геймплейная роль
- Обязателен для нахождения некоторых улик
- Помогает ориентироваться в канализации
- Показывает путь к следующей цели (мягкая подсказка)
- Выявляет скрытые проходы

## 5. Система диалогов

### Движок: Yarn Spinner

### Структура диалога
1. NPC говорит реплику (текст + портрет + имя)
2. Игрок видит варианты ответов (2-4 варианта)
3. Выбор влияет на:
   - Следующую реплику NPC
   - Получение информации
   - Отношение NPC к Пьеру
   - Флаги для концовок

### Условные ветки
- Если у Пьера есть улика → появляется опция «Показать улику»
- Если выполнен побочный квест → NPC реагирует иначе
- Если Пьер уже знает информацию → можно пропустить вступление

### Реплики Пьера (внутренний голос)
- После каждого важного диалога Пьер комментирует про себя
- Помогает игроку понять, что он узнал и что делать дальше
- Ироничный тон, в характере Пьера

## 6. Стелс-система

### Зоны стелса
Стелс активен на Центральной улице и при подходе к мельнице (пока Кошмар патрулирует).

### Обнаружение
- **Поле зрения Кошмара:** конус ~60 градусов, дальность ~15 метров
- **Слух Кошмара:** радиус ~5 метров (бег увеличивает шум до ~10 м)
- **Подкрадывание (Ctrl):** уменьшает радиус шума до ~2 метров

### Состояния AI Кошмара
```
Патруль → Подозрение → Преследование → Потеря цели → Возврат на маршрут
   │           │              │               │
   │      «?» иконка     «!» иконка     Кошмар ищет
   │      2 сек до        Бежит к        ~10 сек
   │      перехода        Пьеру          поиска
   │                                         │
   └─────────────────────────────────────────┘
```

### Индикатор обнаружения
- Над головой Кошмара:
  - Нет иконки — не видит
  - «?» (жёлтый) — подозрение, 2 секунды до тревоги
  - «!» (красный) — обнаружен, преследование

### Укрытия
- Бочки — Пьер залезает внутрь (нажатие E рядом с бочкой)
- Ящики — Пьер прячется за ними (автоматически при подкрадывании)
- Кусты — Пьер скрывается в листве
- Прилавки рынка — можно залезть под прилавок
- Высокие точки — крыши, заборы (Кошмар не может залезть)

### Отвлечение
- Бросить кусок колбасы (если есть в инвентаре): **клавиша T**
- Колбаса летит по дуге, падает
- Кошмар бежит к колбасе, ест ~5 секунд
- Запас колбасы ограничен (можно найти или купить)

### Поимка
- Кошмар добегает до Пьера → анимация поимки
- Комичная сцена «кот в мешке»
- Возврат к последнему чекпоинту

## 7. Ритм-мини-игра (Кошачий концерт)

### Механика
Классическая ритм-игра в стиле Guitar Hero:

1. Музыкальный трек играет на фоне
2. Ноты-иконки движутся по экрану к зоне попадания
3. Игрок нажимает соответствующую клавишу в нужный момент

### Управление
- **A, S, D, F** — четыре дорожки
- Тайминг: Perfect / Good / Miss

### Оценка
- Perfect — точное попадание (±50мс)
- Good — близко (±150мс)
- Miss — промах
- Комбо-множитель за серию Perfect/Good

### Уровни сложности
- **Репетиция** — медленный темп, мало нот (обучение)
- **Выступление** — нормальный темп, полноценная песня (на фестивале)

### Визуал
- Пьер на сцене, поёт / играет на аккордеоне
- Толпа реагирует на качество игры (аплодисменты / свист)
- Фейерверк при полном комбо

### Награда
- Восхищение горожан (влияет на финальную оценку)

## 8. Финальная погоня

### Структура
Линейная скриптовая секция из трёх фаз.

### Фаза 1: Мельница (QTE)
- Пушильда выпускает крыс
- QTE: нажимать указанные клавиши, чтобы уворачиваться
- Промах = укус крысы, замедление
- 3 промаха = провал, рестарт фазы

### Фаза 2: Улицы (погоня)
- Бег за Пушильдой через город
- Управление: WASD + прыжки через препятствия
- Скриптовые моменты:
  - Кошмар просыпается и бежит рядом
  - Крысы блокируют путь → Кошмар разгоняет их
  - Пушильда сбрасывает ящики с балкона → уворачиваться
- Нельзя упустить Пушильду (таймер расстояния)

### Фаза 3: Площадь (финал)
- Пушильда бежит к выходу с площади
- Пьер и Кошмар окружают её с двух сторон
- Скриптовая катсцена загоняния в угол
- Сбегаются горожане → переход в финальную катсцену

## 9. Система подсказок

### Мягкие подсказки
- Внутренний голос Пьера после ~2 минут бездействия: «Может, стоит осмотреться повнимательнее?»
- Кошачий нюх подсвечивает направление к цели
- NPC могут намекнуть в повторном диалоге

### Жёсткие подсказки (после ~5 минут)
- Пьер прямо говорит: «Мне бы стоило заглянуть в бутик Пушильды.»
- Появляется маркер на миникарте

### Настройка
- В меню: «Подсказки» — Вкл / Только мягкие / Выкл

## 10. Система чекпоинтов

### Автосохранение
- При входе в новую локацию
- После нахождения улики
- Перед стелс-секцией
- Перед мини-игрой
- При прогрессе квеста

### Ручное сохранение
- В меню паузы
- На лежанке Пьера (чердак)
