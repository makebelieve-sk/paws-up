## Основной квест: «Дело о пропавшей колбасе»

```
ПРОЛОГ
  │
  ▼
[Q1] Осмотреть лавку Жана
  │  Условие: поговорить с Жаном на улице
  │  Результат: клочок синей ткани, следы, информация о подземном ходе
  │
  ▼
[Q2] Опросить жителей ───────────────────────────────────┐
  │                                                       │
  ├──► [Q2a] Допросить Пушильду                          │
  │     Условие: войти в бутик                            │
  │     Результат: подозрительное поведение                │
  │     Улика: упаковка от трюфелей (мусорное ведро)      │
  │                                                       │
  ├──► [Q2b] Найти информатора в канализации              │
  │     Условие: спуститься в люк                         │
  │     Результат: встреча с Рене                         │
  │     Требуется: сыр (для оплаты)                       │
  │     Улика: карта подземных ходов                       │
  │     Информация: крупный зверь тащил что-то к мельнице │
  │                                                       │
  └──► [Q2c] Поговорить с горожанами (опционально)        │
        Мадам Круассан — слухи                            │
        Рампье — бесполезно, но смешно                    │
                                                          │
  ◄───────────────────────────────────────────────────────┘
  │
  ▼
[Q3] Пробраться к мельнице
  │  Условие: карта от Рене ИЛИ пройти стелс мимо Кошмара
  │  Два пути:
  │    Путь А: через канализацию (безопасно, нужна карта)
  │    Путь Б: через город (стелс-секция с Кошмаром)
  │
  ▼
[Q4] Осмотреть мельницу
  │  Условие: добраться до мельницы
  │  Результат: найти колбасу, спящего Кошмара
  │  Улики: целая попона, запах сыра на ящиках, ящики без клейма
  │
  ▼
[Q5] Разоблачить преступника
  │  Условие: осмотреть всё на мельнице
  │  Результат: появляется Пушильда, признаётся
  │
  │  ┌─── Выбор ───────────────────────────────────┐
  │  │                                              │
  │  ▼                                              ▼
  │  «Сдавайся»                          «У тебя был сообщник?»
  │  «Ещё не поздно»                     (только если ВСЕ улики)
  │  │                                              │
  │  ▼                                              ▼
  │  Стандартная                            Секретная ветка:
  │  погоня                                Пушильда проговаривается
  │  │                                     о пекаре Гастоне
  │  │                                              │
  │  └───────────────┬──────────────────────────────┘
  │                  │
  ▼                  ▼
[Q6] Финальная погоня
  │  Фаза 1: QTE на мельнице (крысы)
  │  Фаза 2: Погоня по улицам
  │  Фаза 3: Загнать на площади
  │
  ▼
[Q7] Развязка
     Концовка зависит от собранных флагов
     (см. 06-endings.md)
```

## Флаги прогресса основного квеста

| Флаг | Как получить | Влияет на |
|------|-------------|-----------|
| `cloth_found` | Найти клочок ткани в лавке | Разблокирует вопрос Пушильде о ткани |
| `truffle_wrapper_found` | Найти упаковку в мусорке Пушильды | Разблокирует обвинение Пушильды |
| `rene_info` | Поговорить с Рене (отдать сыр) | Разблокирует путь через канализацию |
| `underground_map` | Получить карту от Рене | Путь к мельнице через тоннели |
| `cauchemar_vest_intact` | Осмотреть попону Кошмара на мельнице | Доказательство подставы |
| `cheese_smell` | Использовать нюх на ящиках | Указывает на Пушильду |
| `all_clues` | Все улики собраны | Разблокирует секретную ветку |
| `accomplice_revealed` | Спросить о сообщнике | Секретная концовка |

## Побочный квест А: «Потерянный камамбер Рене»

```
[QA1] Рене просит найти его камамбер
  │   Условие: поговорить с Рене после основного диалога
  │
  ▼
[QA2] Найти тоннель под рынком
  │   Условие: карта от Рене
  │   Подсказка: нюх показывает след сыра
  │
  ▼
[QA3] Обнаружить нору мышей
  │   Сыр внутри, мыши его охраняют
  │
  ▼
[QA4] Забрать сыр
  │   Мини-пазл: отвлечь мышей
  │   Вариант 1: бросить крошки в сторону
  │   Вариант 2: использовать нюх, чтобы найти обходной путь
  │
  ▼
[QA5] Вернуть камамбер Рене
      Награда: секретный проход на карте
```

**Флаг:** `rene_quest_done`

## Побочный квест В: «Книга рецептов»

```
[QC1] Жан упоминает старинный рецепт
  │   (в расширенном диалоге, при повторном разговоре)
  │
  ▼
[QC2] Пойти в библиотеку
  │   Поговорить с Месье Бриошем
  │   Он указывает на верхнюю полку
  │
  ▼
[QC3] Достать книгу
  │   Мини-пазл:
  │   • Стремянка стоит далеко → передвинуть (E)
  │   • Стремянка шатается → найти опору (ящик)
  │   • Залезть и взять книгу
  │
  ▼
[QC4] Прочитать рецепт
  │   Обнаружить: трюфели Перигор поставляются
  │   единственным поставщиком в регион
  │   В книге заложена старая накладная:
  │   адрес поставки — бутик Пушильды (!)
  │
  ▼
[QC5] Показать накладную Жану (опционально)
      Жан удивлён: «Пушильда заказывала трюфели?
      Она же говорила, что ненавидит их!»
```

**Флаг:** `recipe_book_clue` → накладная как дополнительная улика

## Побочный квест Г: «Перехитрить Кошмара» (повторяемый)

```
[QD] Пройти стелс-зону разными способами
     │
     ├── Маршрут 1: через крыши (акробатика)
     ├── Маршрут 2: через рынок (укрытия)
     ├── Маршрут 3: отвлечение колбасой
     └── Маршрут 4: через переулки (узкие проходы)

     Каждый новый маршрут = +1 к счётчику стиля
     Все 4 маршрута = достижение «Призрак Сен-Сосиссона»
```
