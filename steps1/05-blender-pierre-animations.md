# Step 05 — Риггинг и анимации Пьера в Blender [Человек]

## Контекст
Blender 5.0.1. Продолжаем с модели из шага 04.
Шаг 5 из 21. Зависит от: Шаг 04.

## Часть 1: Риггинг (создание скелета)

### 1. Создание арматуры
1. Открой `Pierre.blend` (из шага 04)
2. Убедись, что Пьер стоит на 4 лапах, мордой вперёд по оси -Y
3. Numpad 1 (вид спереди), включи рентген: Alt+Z (чтобы видеть кости сквозь модель)
4. Shift+A → Armature → Single Bone
5. Кость появится — это будет корневой `Root` bone

### 2. Построение скелета (Edit Mode арматуры)
Выдели арматуру → Tab (Edit Mode). Строй кости через Extrude (E).

**Схема скелета (21 кость):**
```
Root (центр тела, у пола)
 └─ Spine1 (от Root вверх, центр тела)
     └─ Spine2 (середина тела)
         └─ Spine3 (грудь)
             ├─ Neck
             │   └─ Head
             │       └─ Jaw (опционально, для рта)
             ├─ FrontLeg_L_Upper
             │   └─ FrontLeg_L_Lower
             │       └─ FrontFoot_L
             └─ FrontLeg_R_Upper
                 └─ FrontLeg_R_Lower
                     └─ FrontFoot_R
         └─ (от Spine1) BackLeg_L_Upper
             └─ BackLeg_L_Lower
                 └─ BackFoot_L
         └─ (от Spine1) BackLeg_R_Upper
             └─ BackLeg_R_Lower
                 └─ BackFoot_R
     └─ Tail1 (от Spine1 назад)
         └─ Tail2
             └─ Tail3
                 └─ Tail4
                     └─ Tail5
```

#### Как строить:
1. Выдели кончик кости Root → E → тяни вверх → это **Spine1**
2. С кончика Spine1 → E → вверх → **Spine2** → E → **Spine3**
3. С кончика Spine3 → E → вперёд-вверх → **Neck** → E → **Head** → E → вниз → **Jaw**
4. С кончика Spine3 → E → вниз-влево → **FrontLeg_L_Upper** → E → вниз → **FrontLeg_L_Lower** → E → вперёд-вниз → **FrontFoot_L**
5. Повтори для правой передней лапы
6. Вернись к Spine1 → E → вниз-влево → **BackLeg_L_Upper** → E → вниз → **BackLeg_L_Lower** → E → назад-вниз → **BackFoot_L**
7. Повтори для правой задней лапы
8. От Spine1 → E → назад → **Tail1** → E → E → E → E → (всего 5 хвостовых костей)

### 3. Именование костей
В Properties → Bone → переименуй каждую кость по схеме выше.
Для симметрии: используй суффиксы `.L` и `.R` (Blender автоматически зеркалит).

### 4. Привязка модели к арматуре
1. Object Mode
2. Сначала выдели модель тела (ЛКМ), затем арматуру (Shift+ЛКМ)
3. Ctrl+P → Armature Deform → With Automatic Weights
4. Повтори для глаз и пенсне (чтобы они следовали за головой)

### 5. Проверка и правка весов
1. Выдели модель → перейди в Weight Paint Mode (верхнее левое меню)
2. В Properties → Object Data → Vertex Groups — выбирай кости по одной
3. Красный = полное влияние, синий = нет влияния
4. Проблемные зоны (типичные):
   - **Хвост:** убедись, что Tail кости влияют только на хвост, не на задние лапы
   - **Уши:** привяжи к Head
   - **Платок:** привяжи к Neck и Spine3
5. Рисуй кистью (ЛКМ) чтобы поправить: Add (добавить вес) / Subtract (убрать)

### 6. Тест арматуры
1. Выдели арматуру → Pose Mode
2. Выбирай кости → R → вращай → проверяй деформацию
3. Ctrl+Z чтобы вернуть обратно

## Часть 2: Анимации

Все анимации создаются в **Pose Mode** арматуры. Каждая анимация — отдельный **Action**.

### Общие настройки
1. Выдели арматуру → Pose Mode
2. Открой Dope Sheet (внизу экрана) → переключи на **Action Editor**
3. Timeline внизу: установи FPS = 30 (Output Properties → Frame Rate → 30)

### Анимация 1: `Idle` (60 кадров, зацикленная)
Пьер стоит спокойно, хвост плавно покачивается, уши подёргиваются.

1. Action Editor → New → назови `Idle`
2. **Кадр 1:** A (все кости) → I → Location & Rotation (ключевой кадр для всех)
3. **Кадр 15:** Выбери Tail3, Tail4, Tail5 → R, X → 10° → I. Хвост качнулся вправо
4. **Кадр 30:** Tail3-5 → R, X → -10° (от исходного) → I. Хвост качнулся влево
5. **Кадр 45:** Tail3-5 → R, X → 10° → I (назад вправо)
6. **Кадр 60:** как кадр 1 (копируй кадр 1: кадр 1 → A → Ctrl+C, кадр 60 → Ctrl+V)
7. **Уши (Head):** кадр 20 → R, Z → 3° → I. Кадр 25 → назад → I. Лёгкое подёргивание
8. **Дыхание (Spine2):** кадр 15 → S, Z → 1.02 → I. Кадр 45 → S, Z → 0.98 → I

### Анимация 2: `Walk` (24 кадра, зацикленная)
Четвероногая ходьба. Диагональная схема: левая передняя + правая задняя, потом наоборот.

1. New Action → `Walk`
2. **Кадр 1 (Contact 1):** FrontLeg_L вперёд, BackLeg_R вперёд. FrontLeg_R назад, BackLeg_L назад. Все → I
3. **Кадр 7 (Passing):** Ноги проходят мимо друг друга, тело чуть ниже → I
4. **Кадр 13 (Contact 2):** Зеркально: FrontLeg_R вперёд, BackLeg_L вперёд → I
5. **Кадр 19 (Passing 2):** Зеркальный passing → I
6. **Кадр 24:** Копия кадра 1
7. Spine1-3: лёгкое покачивание вверх-вниз (кадры 1,13 — выше, 7,19 — ниже)
8. Tail: плавное покачивание в противофазе с телом

### Анимация 3: `Run` (16 кадров, зацикленная)
Быстрый бег. Та же схема что Walk, но:
1. New Action → `Run`
2. Бо́льшая амплитуда движения лап
3. Тело сильнее поднимается/опускается
4. 4 ключевых позы на кадрах 1, 5, 9, 13, и кадр 16 = кадр 1

### Анимация 4: `Crouch_Walk` (30 кадров, зацикленная)
Крадётся. Тело прижато к земле.

1. New Action → `Crouch_Walk`
2. **Базовая поза:** Spine1-3 опущены вниз (тело ниже). Лапы согнуты сильнее
3. Медленные шаги, та же диагональная схема как Walk
4. Tail прижат к телу (Tail1 вниз)
5. Head чуть опущена

### Анимация 5: `Sniff` (40 кадров, однократная)
Пьер принюхивается — кошачий нюх.

1. New Action → `Sniff`
2. **Кадр 1:** обычная стойка → I
3. **Кадр 10:** Head опускается вниз, Neck сгибается → I
4. **Кадр 15:** Head поворачивается чуть влево → I
5. **Кадр 20:** Head поворачивается чуть вправо → I
6. **Кадр 30:** Head ещё ниже (нюхает землю) → I
7. **Кадр 40:** возврат в исходную позу → I

### Анимация 6: `PickUp` (30 кадров, однократная)
Пьер подбирает предмет.

1. New Action → `PickUp`
2. **Кадр 1:** стойка → I
3. **Кадр 10:** Spine3 наклоняется вперёд, FrontLeg одна тянется вперёд → I
4. **Кадр 15:** максимальный наклон, лапа "касается" предмета → I
5. **Кадр 25:** возврат назад, Spine выпрямляется → I
6. **Кадр 30:** исходная поза → I

### Анимация 7: `Jump` (20 кадров, однократная)
1. New Action → `Jump`
2. **Кадр 1:** стойка → I
3. **Кадр 4:** приседание (все Spine вниз, лапы согнуты) → I
4. **Кадр 8:** взлёт (Spine вверх, лапы вытянуты вниз) → I
5. **Кадр 14:** полёт (лапы слегка поджаты) → I
6. **Кадр 18:** приземление (приседание при ударе) → I
7. **Кадр 20:** выпрямление → I

## Часть 3: Экспорт

### NLA Editor (организация)
1. Window → перейди в Nonlinear Animation
2. Для каждого Action: нажми "Push Down" — это создаст NLA Strip
3. Это организует все анимации для экспорта

### Экспорт FBX
1. File → Export → FBX (.fbx)
2. Настройки экспорта:
   - **Path:** сохрани как `Pierre.fbx` (рядом с .blend или сразу в `Assets/_PawsUp/Models/`)
   - **Include:** Selected Objects → OFF (экспортируй всё)
   - **Object Types:** ✅ Armature, ✅ Mesh (остальное — по желанию)
   - **Transform:**
     - Scale: 1.0
     - Apply Scalings: FBX All
     - Forward: -Z Forward
     - Up: Y Up
   - **Armature:** Primary Bone Axis: Y, Secondary: X, Add Leaf Bones: OFF
   - **Animation:** ✅ Bake Animation, ✅ NLA Strips, ✅ All Actions
3. Export FBX

### Контрольный список перед экспортом
- [ ] Все transforms применены (Ctrl+A → All Transforms для каждого объекта)
- [ ] 7 Actions в Action Editor / NLA
- [ ] Кости правильно деформируют модель (проверь в Pose Mode)
- [ ] Модель ~0.8 единиц в высоту
- [ ] FBX экспортирован без ошибок
