# Step 04 — Моделирование Пьера в Blender [Человек]

## Контекст
Blender 5.0.1. Создаём 3D-модель кота Пьера Когтеточки — главного героя.
Шаг 4 из 21. Зависит от: ничего (параллельно с шагами 01-03).

## Описание персонажа
Пьер — уличный кот с аристократическими замашками. Полосатый (серый с тёмными полосками).
Аксессуары: маленькое пенсне (очки-пенсне на носу), шейный платок (шёлковый, красный).
Стиль: мультяшный (stylized cartoon), не реалистичный. Упрощённые формы, крупная голова.

## Пошаговая инструкция

### 1. Подготовка проекта
1. Открой Blender 5.0.1
2. File → New → General
3. Выдели куб (ЛКМ) → удали (X → Delete)
4. Установи единицы: верхнее меню → Scene Properties (иконка конуса/плёнки) → Units → Metric, Scale 1.0
5. Вид: Numpad 1 (вид спереди), Numpad 5 (ортогональный)

### 2. Тело
1. Shift+A → Mesh → UV Sphere (Segments 16, Rings 12)
2. S → 0.4 → Enter (масштаб вниз)
3. S, Z → 1.5 → Enter (вытянуть по Z — тело удлиняется)
4. S, X → 0.7 → Enter (слегка сплюснуть по X)
5. Tab (Edit Mode) → включи Proportional Editing (O)
6. Выбери верхние вершины (передняя часть тела) → G, Z → немного вверх → формируй грудь
7. Нижние вершины → G, Z → немного вниз → формируй живот (слегка пузатый — Пьер любит поесть)
8. Tab (назад в Object Mode)
9. Add modifier: Properties → Modifiers (гаечный ключ) → Add Modifier → Subdivision Surface → Levels Viewport: 2

### 3. Голова
1. Shift+A → Mesh → UV Sphere (Segments 16, Rings 12)
2. Переместить наверх тела: G, Z → подними над телом
3. S → 0.5 → Enter (голова крупная — мультяшный стиль)
4. Tab (Edit Mode):
   - **Уши:** выдели 4-5 верхних вершин с одной стороны → E (Extrude) → вверх и наружу → S → сужай кончик. Повтори для второго уха
   - **Морда:** выдели передние вершины → E → немного вперёд → формируй мордочку
   - **Глазницы:** выдели 2 группы вершин по бокам морды → S → немного наружу (для глаз)
5. Tab (Object Mode) → Subdivision Surface modifier, Levels: 2

### 4. Глаза
1. Shift+A → Mesh → UV Sphere (маленькая, scale 0.08)
2. Размести у правой глазницы
3. Дублируй (Shift+D) → перемести к левой глазницы
4. Глаза должны быть крупными (мультяшный стиль!)
5. Зрачки: Shift+A → UV Sphere ещё меньше (scale 0.03), чёрный материал, перед каждым глазом

### 5. Лапы
1. Shift+A → Mesh → Cylinder (Vertices 8, Depth 0.4, Radius 0.08)
2. Tab → выдели нижние вершины → S → 1.3 (расширь — подушечки лап)
3. Object Mode → разместить под телом (правая передняя)
4. Shift+D → зеркально отрази для остальных 3 лап (Mirror по X, перемести по Y)
5. Итого 4 лапы: 2 передние, 2 задние (задние чуть толще и длиннее)

### 6. Хвост
1. Shift+A → Mesh → Cylinder (Vertices 8, Depth 1.0, Radius 0.04)
2. Tab → выдели верхние вершины → S → 0.3 (кончик тоньше)
3. Object Mode → размести сзади-снизу тела
4. Поверни: R, X → 45 (хвост вверх под углом)
5. Добавь modifier: Properties → Modifiers (гаечный ключ) → Добавить модификатор → Деформация → **Простая деформация** (Simple Deform) → Mode: Изгиб (Bend) → Angle 30° (плавный изгиб)

### 7. Пенсне (очки)
1. Shift+A → Mesh → Torus (Major Radius 0.04, Minor Radius 0.005)
2. Дублируй → сдвинь — два колечка для линз
3. Shift+A → Mesh → Cylinder (очень тонкий, radius 0.003, depth 0.08) — мостик между линзами
4. Размести на носу Пьера
5. Объедини (выдели все 3 → Ctrl+J)

### 8. Шейный платок
1. Shift+A → Mesh → Plane
2. S → 0.15 → Enter
3. Tab → Subdivide 3 раза (ПКМ → Subdivide)
4. Формируй вершины вокруг шеи: G, тяни, формируй складки
5. Extrude края вниз для свисающих концов платка
6. Solidify modifier (thickness 0.005) чтобы придать объём

### 9. Объединение
1. Выдели ВСЕ части (A) кроме глаз и пенсне
2. Ctrl+J (Join) — объедини тело, голову, лапы, хвост, платок в один меш
3. Глаза и пенсне оставь отдельными объектами (для будущих Shape Keys)
4. Выдели тело → Ctrl+A → All Transforms (применить масштаб и поворот)

### 10. UV-развёртка
1. Выдели тело → Tab (Edit Mode)
2. A (всё) → U → Smart UV Project → OK
3. Открой UV Editing workspace (верхние вкладки)
4. Поправь островки: уши, морда, лапы, хвост — по отдельным островкам
5. Object Mode

### 11. Материалы
1. Выдели тело → Properties → Material → New
2. **Fur_Main:** Base Color — серый (#8B8B8B), Roughness 0.8
3. New Material slot → **Fur_Stripes:** тёмно-серый (#4A4A4A) — для полосок (назначь в Edit Mode на выбранные фейсы спины/хвоста)
4. **Scarf:** Base Color красный (#CC2222), Roughness 0.6 — на фейсы платка
5. **Eyes_White:** белый, Roughness 0.3
6. **Eyes_Pupil:** чёрный, Roughness 0.1, Specular 0.8
7. **Pince_Nez:** Base Color золотистый (#C4A236), Metallic 0.9, Roughness 0.2
8. **Pince_Lens:** прозрачный (Alpha 0.2, в Surface → Settings → Blend Mode: Alpha Blend)

### 12. Финальная проверка
- Пьер стоит на 4 лапах, хвост вверх
- Голова крупная, морда выразительная
- Пенсне на носу, платок на шее
- Общая высота: ~0.8 единиц (80 см в мире Unity)
- Общий polycount: 5000-15000 полигонов (мультяшный стиль, не нужно много)
- Ctrl+S → сохрани как `Pierre.blend`

**НЕ экспортируй пока в FBX** — сначала нужен риггинг и анимации (шаг 05).
